编译知识，而非检索碎片。

一个由 LLM 自动维护的个人知识库。丢入原始资料，Claude 会提取实体、构建互联的 Markdown 页面、注入维基链接、追踪可信度并标记矛盾。生成的是完全属于你的纯 Markdown 文件，可直接在 Obsidian 中浏览。

你能得到什么

结构优先，向量可选。

实体、概念与维基链接构成一张真正的知识图谱：那是你可以打开、阅读、手动编辑的文件。

一张知识图谱，而非一团向量

每份资料都会被编译成互联的 Markdown：实体、概念、对比、综合。PageRank 中心度决定什么更重要。在 Obsidian 中打开 wiki/，即可获得实时图谱视图、反向链接与悬停预览。

默认增量更新

SHA-256 变更检测意味着只有新增或修改过的资料会被重新处理。知识库再大，重编译也依然快。

回溯式链接

摄入一个新主题，已有页面会自动补上指向它的 [[维基链接]]。图谱在生长中自我修复。

自我修复的质量体系

贝叶斯可信度评分、跨资料矛盾检测、内容过期标记与死链检查，全部自动完成。

MCP 优先，兼容 CLI

为什么不用 RAG？

RAG 检索文本块，本系统理解知识结构。

传统 RAG
  • 你无法阅读或浏览的向量嵌入
  • 彼此之间没有关系的文本块
  • 只能指望 Top-K 片段刚好相关
  • 资料一变就要全量重新向量化
  • 静默地返回互相矛盾的片段
LLM Wiki Flywheel
  • 可在 Obsidian 中浏览的 Markdown 页面
  • 实体与维基链接构成的知识图谱
  • BM25 + 向量混合排序，叠加可信度评分
  • 增量编译，只处理变更的资料
  • Lint 自动跨资料检测矛盾
