Ingest auto

Web, PDF, video, repos → markdown. Extract entities, concepts & claims from each source with scan/write model tiers.

Compile auto

Build interlinked pages, inject [[wikilinks]] retroactively, rebuild the PageRank graph and vector index, incrementally via SHA-256.

Query auto

Hybrid BM25 + vector search with RRF fusion, tiered context and stale flagging. Output adapters: markdown / marp / html / chart / jupyter.

Lint auto

Dead-link detection, cross-source contradiction checks, staleness flags and Bayesian trust scoring keep the wiki self-healing.

Evolve auto

Coverage-gap analysis surfaces missing pages and new connections, feeding the next turn of the flywheel.

Continuous

Every operation feeds the next. Add one source and extraction, linking, checks and evolution all compound, with no human in the loop after curation.

Subsystems

The infrastructure that makes the flywheel fast, trustworthy, and zero-config.

MCP Server

28 tools exposed to Claude Code: ingest, query, search, trust, browse, compile, health. No API key required.

Hybrid Search

BM25 + model2vec vectors fused with Reciprocal Rank Fusion, re-ranked by PageRank centrality and trust.

Model Tiers

Scan (Haiku) for mechanical reads, Write (Sonnet) for authoring, Orchestrate (Opus) for reasoning & verification.

SQLite DB

Local, file-based store for the graph, edit history, lint verdicts and the sqlite-vec vector index.

Memory Graph

Typed entity relations power retroactive wikilink injection and cross-page contradiction detection.

Obsidian Vault

Open wiki/ as a zero-config vault for a free graph view, backlinks and hover preview.
